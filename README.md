# ViaCEP API

API para consulta de enderecos brasileiros a partir do CEP. Gratuita, sem cadastro.

## Exemplo de resposta

```
GET /api/cep/01310100
```

```json
{
  "cep": "01310-100",
  "logradouro": "Avenida Paulista",
  "complemento": "de 610 a 610 - lado par",
  "bairro": "Bela Vista",
  "cidade": "Sao Paulo",
  "estado": "SP",
  "ibge": "3550308",
  "ddd": "11"
}
```
